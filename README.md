# SI-BOP RT (Sistem Informasi Bantuan Operasional RT)
### RT 04 / RW 04 Kelurahan Gunungpati, Kecamatan Gunungpati, Kota Semarang

Aplikasi web untuk pengelolaan dan pertanggungjawaban dana Bantuan Operasional RT (BOP RT) dari APBD Kota Semarang.

## Fitur Utama
- **Dashboard & Recharts**: Grafik batang interaktif perbandingan anggaran RAP dan realisasi pengeluaran bulanan.
- **Pengambilan Bulanan**: Format permohonan pengambilan operasional RT melalui Bank Jateng sesuai RAP.
- **Pelaporan & Bukti SPJ Bulanan**: Modul unggah/input notulen RT, notulen PKK, daftar hadir, foto kegiatan, foto barang, dan foto nota.
- **Laporan & SPJ Buku Kas Umum**: Rekapitulasi otomatis untuk pelaporan ke Kelurahan.
- **Rencana Anggaran (RAP)**: Pengaturan alokasi anggaran 1 tahun penuh.
- **Musyawarah Warga**: Pencatatan Berita Acara dan daftar hadir musyawarah.
